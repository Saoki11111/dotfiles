# Git PR Prompt

この変更内容からPull Requestを作成してください。
PR本文には、変更内容、確認方法、影響範囲を具体的に書いてください。

## 前提

- `main` へ直接pushしない。
- 作業branchを作る。
- commit後にpushする。
- CI確認後にmergeする。

## PR本文テンプレート

```md
## 概要

- 

## 変更内容

- 

## 確認方法

- [ ] 

## 影響範囲

- 

## リスク

- 

## 補足

- 
```

## AIに依頼したいこと

- 変更差分を確認する。
- 適切なbranch名とcommit messageを提案する。
- PR本文を作成する。
- 可能ならPR作成まで実行する。
