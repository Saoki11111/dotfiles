# HP Renewal Project

HPリニューアル案件用のメモです。

## 目的

- 会社HPの見た目、情報整理、運用性を改善する。
- 社長、上司、関係者が判断しやすい形で説明する。
- 公開後に更新しやすい構成にする。

## 確認者

- 社長確認: 方針、印象、公開判断、費用感。
- 上司確認: 業務面、社内調整、運用体制。
- 制作者確認: 実装、デザイン、CMS、公開作業。

## デザイン調整

- 会社の信頼感を優先する。
- 派手さより、分かりやすさと見やすさを重視する。
- スマホ表示を必ず確認する。
- 文字量、写真、余白、問い合わせ導線を確認する。

## 公開判断

- 公開URL、ドメイン、SSLを確認する。
- 問い合わせフォームの送信確認をする。
- 誤字、リンク切れ、画像崩れを確認する。
- 公開日、告知方法、戻し方を決める。

## 費用・運用・セキュリティ説明

- 初期費用、月額費用、追加費用を分けて説明する。
- 誰がどこを更新するかを明確にする。
- CMS、外部API、フォーム、ドメイン、サーバーの管理者を確認する。
- APIキー、管理画面権限、バックアップ方法を確認する。

## 次回プレゼンで話す観点

- 現状HPの課題。
- 新HPで改善される点。
- デザイン案の方向性。
- 公開までの流れ。
- 費用と運用体制。
- 決めてほしいこと。
